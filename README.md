## Download

Get the latest installer from the [**Releases**](https://github.com/Theoxking1/the-hub/releases/latest) page → `the-Hub-Setup-x.x.x.exe`.

Windows SmartScreen may warn ("unknown publisher") since the app isn't code-signed — click **More info → Run anyway**. After the first install, the Hub keeps itself up to date automatically.

## What it does

- 🎮 **All your launchers, one window** — auto-detects the major storefronts; add any others yourself.
- 🕹️ **Built for the couch** — full controller navigation and an on-screen keyboard, just as happy on a TV as a desk.
- 📄 **Real game pages** — cover art, your playtime, "how long to beat," and one-click launch.
- 🛒 **Browse stores in-app** — Steam, Epic, GOG and the rest, without leaving the Hub.
- 🎨 **Make it yours** — custom colour themes and backgrounds.
- 💾 **Save-file backup** — keep your saves safe.
- 🟣 **Discord presence** — show off what you're playing.
- 🔄 **Updates itself** — new fixes install quietly in the background.

## Supported launchers

**Storefronts** — Steam · Epic Games · GOG · Xbox / Microsoft Store · EA · Ubisoft Connect · Battle.net · Amazon Games · Rockstar · itch.io

**Libraries & retro** — Playnite (native, manual & emulated games) · LaunchBox (retro and console libraries)

The major storefronts are detected automatically; anything else you can add yourself in a couple of clicks.

## Controls

Full keyboard **and** controller support — it's built to run from the couch.

| Button | Does |
| --- | --- |
| **A** | Open / select |
| **X** | Launch the game |
| **Y** | Expand a launcher's list · open a game's menu |
| **B** | Back |
| **Start** | Settings |
| **D-pad / stick** | Move around |

There's a built-in on-screen keyboard for search and text, so you never have to reach for a mouse.

## Requirements

- Windows 10 or 11
- Whatever launchers you want it to see (Steam, Epic, …) installed normally
