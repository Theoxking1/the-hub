# the Hub

One window for every game launcher on your PC. Steam, Epic, GOG, Xbox, Battle.net and more, with full controller/couch support.

**Still in beta — looking for feedback and ideas.** Found a bug or have a suggestion? Open an [issue](https://github.com/Theoxking1/the-hub/issues).

## Download
Grab the latest installer from the [Releases](https://github.com/Theoxking1/the-hub/releases) page. Windows SmartScreen may warn ("unknown publisher") since it's unsigned — click **More info → Run anyway**.
